# 双星 Star Battle · 区域双星推理

一个零猜测的益智盘：`N×N` 被切成 `N` 个不规则区域，**每行、每列、每个区域正好两颗星，
任何两颗星都不能相邻（含斜角）**。盘上不印任何数字——**分区图本身就是线索集**，
你能看见的每一条边界都在缩小组合空间。

本页每一个数字都是本轮重跑量出来的：HEAD `a656367`、Node `v26.8.1`、macOS、
2026-09-28 03:00–03:20 CST 一次会话，跑的命令是 `npm run check` / `node tools/engine-test.mjs` /
`SAMPLES=24 node tools/balance.mjs` / `bash tools/verify.sh`。出处写在每张表下面。
**这台机器当时被邻居压着（load1 36.3）**，所以凡是以毫秒计的量都单独标注，且见下文「不承诺」。

**代码 > 本文档**：本文与 `js/`、`tools/` 冲突时，以代码和它跑出来的输出为准。

## 规则（玩家视角）

- 盘是 `N×N`，被切成 `N` 个连通区域，形状完全不规则——区域不是提示，是题目的一部分。
- **每行、每列、每个区域都正好两颗星**；任何两颗星不能共边，也不能共角。
- 一格有三种状态：空、星、灰（铅笔排除标记，"这格放不了星"）。灰色不是答案的一部分，
  但它是这条推理链的账本——本盘不猜，所以每一步都得写下它为什么不可能。
- 判胜只有一件事：18 颗星（8×8 是 16 颗）全部落定，且三条"正好两颗"和不相邻同时成立。

## 六条铅笔规则（提示只会说这六条里的一条）

规则按"一次应用真实花掉玩家多少铅笔"排序，权重是 `1, 1, 2, 3, 4, 6`
（`js/engine/rules.js:33-71`，顺序写在 `:76`，`tools/engine-test.mjs:654` 把这条序列钉死，
`:665` 还钉了一颗盘的回归分数——动权重就会在那里红）：

| # | 规则 | 权重 | 它在说什么（提示文案的原型） |
|---|------|------|------------------------------|
| ① | 星的邻域 | 1 | `X 放了星，它的八邻域（含斜角）都不能再放——Y 标灰` |
| ② | 满额排除 | 1 | `U 的 2 颗星已经放满，其余 n 格都不能再放——Y 标灰` |
| ③ | 只差这些 | 2 | `U 还差 k 颗星，而它只剩 k 格可放——这些格每一格都必须放星` |
| ④ | 摆不下 | 3 | `Y 不在 U 任何一种合法摆法里（谁跟它配都不行）——标灰` |
| ⑤ | 只剩这一对 | 4 | `U 还差 2 颗，可放格有 n 个，但互不相邻的摆法只剩一种——Y 必须在内` |
| ⑥ | 试放即死 | 6 | `Y 若放了星，会……——所以这格只能标灰`（逐格做一小段反证） |

①② 是一行计数；③ 要盯着一个单元的余格看；④⑤ 要把该单元的**完整摆法集合**枚举一遍；
⑥ 每一格都要重推一遍。**权重不是拍出来的**：它们被拿去量过分位，量出来的分布就是下面那张阶梯表
（为什么"只能用确定性量"见 `DESIGN.md` §8）。

## 为什么阶梯是 8×8 起、9×9 止（这一段是复算的，不是引经据典）

`每行每列两颗、互不相邻` 的合法摆法数——穷举器与记忆化 DP 各算一遍，两把尺共享零行代码：

```
4×4 0 ／ 5×5 0 ／ 6×6 0 ／ 7×7 0 ／ 8×8 2 ／ 9×9 664 ／ 10×10 146510
```

本轮两种方法**逐位对上**（`balance.mjs` 每次跑都重打这张表）。所以 `MIN_SIZE = 8`
（`js/engine/generate.js:205`）：**5×5 和 6×6 根本没有合法盘**，不是"太难"或"太简单"，是 0 个解。

10×10（比赛尺寸）今天仍然**不可出货**：随机切 20 次 → 16 次切出连通分区，其中**铅笔推得完 0 次**；
局部搜索另搬 6 次，仍然 0 次；未定格数中位 **92/100**（p95 100）。同一次跑的 9×9 对照：
2/19 可推完、中位 26/81 格未定。要么放松"唯一"、要么放松"推到底"，两条都不在谈判桌上——所以阶梯止于 9×9。

## 文档里印着的行号，由一条会红的断言管着

这两份文档里有几十句「去看第 N 行」。写这些话的时候没有任何机器核过：改了代码不重编行号，文档不会响，
读者按图索骥找到的是隔壁那几行。`tools/docs-test.mjs`（499 行）把那句话变成一条断言，判四件事——文件在不在
盘上、行号落在不在该文件的真实行数内、被指的那几行是不是整段空白（"在界内"不等于"指到了代码"），以及
贴着引用的那个名字是否真的作为**完整标识符**出现在被指的那几行里（子串口径会把一次真的漂读成绿：
`node` 坐在 `let nodes = 0;` 那一行上也算"出现"）。

本轮读数住在 `node tools/docs-test.mjs` 自己的 stdout 里（2026-10-08 这一跑）：**解析 46 条 · 续引 3 条 ·
无法定址 0 处 · 10 条带指认 · 跨仓引用 1 处 · 文档行号对账 32 条判据**。这些数是等式而不是修辞：文档里每一处
「解析 N 条」都必须等于闸当场解析到的条数，写歪一格就红——只写下限抓不住"文档抄的是上一轮那个数"。

- **续引**：完整引用后面只写冒号行号的那种，向同一句里最近的一条完整引用借路径；句号、分号、空行、新标题都
  关上这次借的窗口，借不到就计入「无法定址」，不静默跳过。这条腿落地第一次跑的时候本仓有 6 处借不到——
  都是 DESIGN 里那种"前面只坐着一个没有行号的文件名"的写法，现在补成了带路径的完整引用。
- **跨仓那 1 处**是 DESIGN §5 引兄弟仓摩天楼的 `generate.js` 那一行：单仓 checkout 里根本读不到那个文件，
  拿"文件在不在"判它就是一条随环境漂的闸（CI 里必红、换台机器绿），所以这条腿只数它、不为它的行号担保。
- **`path`（N 行）这种写法同样当等式**：上面那句里印的行数写歪一个数字就红。这条腿的取样池递归扫盘，
  仓根那几个文件（`sw.js`、`server.cjs`）也在池里；而它的覆盖面**不是由那份目录名单自己担保的**——尺子是
  盘上的**第二遍独立遍历**，逐文件比（名单会自我实现：把 `TARGET_DIRS` 改成只剩一棵树，"每棵树都进得来"
  那句 every() 跟着变短而照样绿；只按目录比也照不出"漏了仓根的一个文件"，因为仓根根本不在尺子下）。
  本仓的台架第一版就是这样下了刀、红了 0 格，所以修的既数"漏了哪些文件"也数池子够不够大。

**这一腿没覆盖什么**：

- 它只证明印在纸上的行号还坐在它所描述的那几行上，**不证明周围的句子**。把「这一行是 `nextForced()`」改成
  「这一行是 `solve()`」，只要 `solve` 也出现在被指的那几行里，它就照绿。
- 它不跑引擎、不开浏览器，所以也不核那些**读数本身还新不新**：`node tools/engine-test.mjs` 的 357 与
  `bash tools/verify.sh` 的 798 各由自己的命令判，文档抄的只是上一跑的 stdout。
- 浏览器闸那串场景读数由一条自己的等式管着（每一处 boot+gen+play+hint+win 的五数之和等于同一句里写的总数，
  且 README / DESIGN / ci.yml 三处抄的总数互相相等）——钉的是**抄得自洽**，不是读数还新。
- 本仓没有 `test/` 目录，所以家族里"进链但不进 `npm run unit` 那个 test/*.test.mjs 循环"那一格在这里没有
  对应物，换成了两格：README「跑起来」印的每一条 npm 命令必须在 `package.json` 的 scripts 里真存在；
  `package.json` 里每条跑 `tools/` 的门禁，它的每一条调用必须在文档或 CI / verify.sh 里被点到——
  一条谁都不点的门禁等于没有。

### 下刀台账

"这条闸会红"是一句需要自己挨一刀的话。台架是**仓外**的一份副本（`_scratch/starbattle-docs-teeth/` 下的
一棵树，它不进 `npm test`、不随仓发货），每把刀只改副本里的一个文件、改完立刻要求整闸回绿——
红留在台上，不留在树里。五条规矩全是被咬过的坑换来的：判定只认 `  FAIL ` 行的原文（绿只打计数不打名字）；
每把刀断言的是红的**总数**而不是正则命中的子集（一条多红的会从这个口径里溜走而台架照样打 ok）；
刀不许改文件行数，一律同行改写（插一行就挪行号，别的格子跟着红，一台架说不清是谁咬的）；
红格子数不是推理出来的——K7 与 K18 那两把先在同样形状的副本上单独量过一遍，把读数抄回来当期望值；

  是分数分位，不是毫秒），最贵的一次穷举证明仍然落在高阶的 1694 节点。分布仍然宽——初学档自己

  没有任何一道闸断言过墙钟：本轮 grep 过 `tools/balance.mjs`，`ms` 只在 `tools/balance.mjs:168-175` 被量、

## 上线的到底是哪一批文件

这个仓没有打包器：站点=一次文件拷贝。以前「拷哪些」写在 `pages.yml` 的 `run:` 里（手抄的几行
`cp`）。本地 `index.html` 直读仓库根，永远自洽；线上却按那份清单拷，于是页面后来引用的
`manifest.webmanifest`、`sw.js`、`icons/*` 可能一个都没上去——线上 404，而仓里的引擎测试与
真浏览器闸全绿，因为它们跑的都是仓库根，没有任何一步在「按清单拷」的那个环境下加载过页面。

现在清单只有一份，住在 `tools/assemble-site.sh`：CI 调它拷 `_site`，本地闸调它拷临时目录，
然后**对拷出来的产物**提要求（`tools/deploy-set.mjs`）：

- **W 清单与页面同源**：`pages.yml` 里必须真有 `run: bash tools/assemble-site.sh <dir>` 这一行，
  `ci.yml` 里必须真有 `run: node tools/deploy-set.mjs`。认的是调用那一行，不是文件里出现过这个
  路径——注释里本来就会写它，只 grep 字符串会被一句散文喂绿。
- **R 引用可达**：引用不靠手打名单。从 `index.html` 的 `href/src` 出发，凡解析出来是 `.js`/`.css`
  的就把那一站也扫一遍（CSS 的 `url()`、JS 去掉注释后的 `'./…'` 字面量、`new URL(x, base)` 的两种
  基、`navigator.serviceWorker.register`、`scope`），`manifest` 的 icons/screenshots/shortcuts 各自
  的 `src` 也算引用。取径上读不到的那一站本身就是红（读不到＝这一站根本没扫）。每条引用都必须在
  产物里且非 0 字节；绝对路径单列一条红，因为 Pages 挂在 `/<repo>/` 前缀下会跳出去。
- **P 位图不许说谎**：`manifest` 声明的 `sizes` 必须等于 PNG IHDR 的真实宽高——文件图标读文件头，
  内联成 base64 的图标先解码再读同一段。后一条不是可选项：图标可能住在清单里而不是盘上的 `.png`
  （有的仓另有一条"零二进制文件"的承诺，那条只约束"有没有 .png 这个文件"）；如果 P 段只筛文件名，
  声明写 512 而真图 192 就一路放行。
- **钉住两个数**：R 段实际检查的路径条数（`32`）与这一次跑的断言条数（`50`），两个数
  都钉在 `tools/deploy-set.mjs` 顶部的那对常量里。没改页面却掉了，说明解析断了；删掉一张图标会同时
  少一条 R10 与那张的 P1/P2，所以两个数一起钉，断言条数能漂就是闸在缩水的信号。这一节故意只写数值、
  不写那对常量的名字，也不写别仓文档闸的编号：有的仓的文档闸会拿"文档里出现过的同名标识号"回数它
  自己的条数，还有的会把文档里点到的每个组编号逐个核对"这一轮真的发过"——两道闸共用一个名字，
  或者在本仓的文档里出现一个本仓没有的组编号，打红的都是不相干的那一边。

`tools/deploy-set-selftest.mjs` 是这两颗钉的阳性证明：它把仓库复制到临时目录，照着每一类断言
各下一刀（X1 清单不收位图目录 / X2 模块边改名 / X3 CSS 写绝对路径 / X4 `start_url` 绝对 /
X5 删光 >=512 图标 / X6 少一个必填字段 / X7 声明尺寸与真图不符 / X8 workflow 不调脚本 /
X9 CI 不跑闸 / X10 是阴性对照——往入口 JS 追加一行只写在注释里的假路径，闸必须仍然绿、条数仍然
`32`、断言仍然 `50`；X11 og:image 退回相对路径 / X12 og:image 的前缀指向别的 slug /
X13 内联位图谎报尺寸——只在有靶子时下：X11/X12 要页面上那句 og:image，X13 要清单里真有一段 base64
图标，没有就打印 SKIP；反过来 X1 没有位图目录可砍时改砍 css，P 段一位都不核时台架直接报靶子不够），
要求每一刀都让闸**点名**变红。靶子从 `DEPLOY_SET_DUMP=1`
的出处表现挑（取径真的会读的那支 JS / 那一张 CSS，不写死某一个仓的入口名），所以页面改了、仓与仓
不同，台架跟着走。

`node tools/deploy-set.mjs` 与 `node tools/deploy-set-selftest.mjs` 就是 CI 跑的那两条命令本身
（package.json 里的 `deploy-set` / `deploy-set:selftest` 只是同一支脚本的 npm 入口）；本仓的整闸在 `tools/verify.sh` 的 `=== deploy-set ===` 那一段也各跑一次。它们红的时候并进本仓那条出口的退出码——这一条是这么证的：
把 ci.yml 里那行 `run: node tools/deploy-set.mjs` 砍掉，本仓整闸必须点名红且退出码非 0。
所以「本地全绿、线上 404 自己的 manifest / sw.js / 图标」这一类坏法在本地就会红。
